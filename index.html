Plutonium Lite

Warning

These features do not work in Plutonium Lite: proxy, accounts, cloud gaming, backgrounds, AI chat, and virtual machines.

Three ways to load Plutonium when the usual domain is blocked. Pick whichever one your setup allows, or link straight to a file through one of the hosts listed under each card.

1. Single page

versions/plutonium.html

One self contained HTML file. Everything it needs is pulled at load time, so nothing else has to sit next to it.

  1. Open the file directly: plutonium.html.
  2. To share it, host the file anywhere or send the file itself.
  3. Anyone who opens it gets the full app in a single tab.
jsDelivrhttps://cdn.jsdelivr.net/gh/Plutonium-Net/Lite@main/versions/plutonium.html
githackhttps://raw.githack.com/Plutonium-Net/Lite/main/versions/plutonium.html
htmlpreviewhttps://htmlpreview.github.io/?https://github.com/Plutonium-Net/Lite/blob/main/versions/plutonium.html

2. Data URI

versions/plutonium.txt

The same page encoded as one long data: URI. Useful when you cannot open or host a file at all.

  1. Open plutonium.txt and copy the whole line.
  2. Paste it into the browser address bar and press Enter.
  3. Or save it as a bookmark so it is one click later.
jsDelivrhttps://cdn.jsdelivr.net/gh/Plutonium-Net/Lite@main/versions/plutonium.txt
githackhttps://raw.githack.com/Plutonium-Net/Lite/main/versions/plutonium.txt
htmlpreviewhttps://htmlpreview.github.io/?https://github.com/Plutonium-Net/Lite/blob/main/versions/plutonium.txt

3. SVG wrapper

versions/plutonium.svg

The app wrapped in an SVG document. Handy where an image file is allowed but an HTML page is not.

  1. Open the file directly: plutonium.svg.
  2. Or embed it like any other SVG.
  3. It runs the same app inside the SVG viewport.
jsDelivrhttps://cdn.jsdelivr.net/gh/Plutonium-Net/Lite@main/versions/plutonium.svg
githackhttps://raw.githack.com/Plutonium-Net/Lite/main/versions/plutonium.svg
htmlpreviewhttps://htmlpreview.github.io/?https://github.com/Plutonium-Net/Lite/blob/main/versions/plutonium.svg

All three load the same build and share the same feature set. Each card lists three hosts for the same file. jsDelivr serves the HTML file as plain text, so use that link to download or copy, while the githack and htmlpreview links open the HTML file as a running page.
